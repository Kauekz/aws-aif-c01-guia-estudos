# AWS Certified AI Practitioner (AIF-C01) | Guia de Estudos

Repositório com resumos, conceitos essenciais e anotações técnicas compiladas durante uma preparação intensiva de 10 dias para o exame AWS Certified AI Practitioner.

Todo o material foi estruturado com base no guia oficial da prova: [AWS Certified AI Practitioner (AIF-C01) Exam Guide v1.2](https://docs.aws.amazon.com/pdfs/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.pdf).

## Estrutura do Repositório (Domínios do Exame)

* **[Domínio 1: Fundamentos de IA e ML (20%)](./Dom%C3%ADnio_1_-_Fundamentos_de_IA_e_ML.md)**
  Conceitos básicos de Inteligência Artificial, tipos de aprendizado (supervisionado, não supervisionado, reforço), inferência e serviços gerenciados da AWS.
* **[Domínio 2: Fundamentos de IA Generativa (24%)](./Dom%C3%ADnio_2_-_Fundamentos_de_IA_Generativa.md)**
  Foundation Models (FMs), tokens, embeddings, arquitetura RAG, casos de uso corporativos e Amazon Bedrock.
* **[Domínio 3: Aplicações de Modelos de Fundação (28%)](./Dom%C3%ADnio_3_-_Aplica%C3%A7%C3%B5es_de_Foundation_Models.md)**
  Engenharia de prompt, técnicas de customização (Fine-tuning vs. RAG), avaliação de performance de modelos e otimização de custos.
* **[Domínio 4: Diretrizes para IA Responsável (14%)](./Dom%C3%ADnio_4_-_IA_Respons%C3%A1vel.md)**
  Mitigação de viés (bias), alucinações, transparência, explicabilidade e aplicação de controles como o Bedrock Guardrails.
* **[Domínio 5: Segurança, Conformidade e Governança (14%)](./Dom%C3%ADnio_5_-_Seguran%C3%A7a__Conformidade_e_Governan%C3%A7a.md)**
  Modelo de responsabilidade compartilhada para IA, proteção e privacidade de dados, IAM, criptografia, auditoria e governança na AWS.

## Principais Serviços Abordados

* **IA Generativa e ML:** Amazon Bedrock, Amazon SageMaker (JumpStart, Clarify, Model Monitor), Amazon Q.
* **Serviços de IA Prontos:** Amazon Comprehend, Amazon Rekognition, Amazon Textract, Amazon Polly, Amazon Transcribe, Amazon Personalize.
* **Segurança e Governança:** AWS IAM, AWS KMS, Amazon Macie, AWS CloudTrail, AWS Artifact, AWS Audit Manager.
